Campus Autonomous Navigation & Delivery Vehicle

Designed, architected, and deployed a robust computer vision-driven autonomous control framework engineered for real-time obstacle perception, spatial awareness, and dynamic path navigation. The core perception pipeline combined traditional OpenCV image processing techniques for lane and edge tracking with custom-trained YOLO (You Only Look Once) object recognition models, fine-tuned to classify and track dynamic obstacles such as pedestrians, bicycles, and urban debris under varying lighting conditions.Originally, the software architecture was conceptualized and simulated for a full-scale passenger campus shuttle. To evaluate system viability, test hardware-software integration constraints, and minimize deployment risk, the full vision and control stack was scaled and ported onto a functional, medium-sized autonomous delivery robot prototype. This transition required building a responsive interface between high-level vision inferencing and low-level motor microcontrollers.The physical platform underwent rigorous, multi-phase field testing across active university campus environments. The deployment successfully validated point-to-point payload delivery capabilities, proving the vision stack’s real-time reliability, low-latency decision-making, and structural resilience when navigating unstructured, unpredictable human environments.

Spark Detection and Automatic Power Cutoff System

Designed, engineered, and implemented an embedded electrical safety system designed to detect hazardous AC outlet arcing by capturing and analyzing high-frequency power line noise on an Arduino microcontroller platform. Electrical arc faults—a leading cause of structural electrical fires—generate distinct high-frequency transient signatures along the AC voltage waveform. The system continuously monitors these line distortions to differentiate dangerous arcing events from benign switching noise created by standard household loads.To achieve reliable, real-time detection without risking component failure, the system utilizes an analog signal-conditioning front-end to safely isolate high-frequency spectral components while protecting the low-voltage microcontroller logic. Custom embedded algorithms process the incoming voltage signatures, detecting micro-sparks and sporadic breakdown voltage patterns before thermal accumulation can ignite surrounding materials.Upon identifying a verified arc condition, the controller immediately executes a hardware safety routine, energizing a high-speed relay to trip the primary circuit and physically isolate the fault. By interrupting power within milliseconds of initial spark formation, the prototype dramatically lowers high-current hazards, offering an accessible, low-cost approach to arc-fault circuit protection.

Embedded System and Control Panel For Complex Systems

Designed and built an end-to-end mechatronic control platform featuring a custom graphical user interface (GUI) developed in Python (Tkinter) that interfaces seamlessly with an Arduino microcontroller via high-speed serial (UART) communication. The desktop interface provides real-time telemetry, manual actuation controls, and dynamic parameter tuning, enabling centralized, user-friendly control over complex underlying hardware.On the hardware side, the system controls a high-torque mechanical powertrain utilizing a DC motor paired with a multi-stage gear system. Pulse-Width Modulation (PWM) and dedicated driver circuits were implemented to achieve precise speed regulation and torque management under varying load conditions. Concurrently, the firmware manages multi-axis servo motor actuation for articulate mechanical positioning alongside an array of electrical sensors (such as rotary encoders, current monitoring, or optical distance sensors).To ensure seamless performance, the embedded firmware and host software were optimized for non-blocking execution, allowing real-time processing of high-frequency sensor streams without introducing latency into motor control loops. The end result is a unified, scalable hardware-in-the-loop (HIL) platform capable of precise, synchronized actuation across complex mechanical assemblies.

Grid-Tie Inverter System

Designed, constructed, and tested a prototype grid-tie inverter system utilizing an Arduino microcontroller to safely convert low-voltage DC into synchronized AC power for grid injection. To overcome the critical challenge of matching grid phase and frequency, the system incorporates an optocoupler-based Zero-Crossing Detection (ZCD) circuit. This provides full galvanic isolation between high-voltage AC mains and sensitive low-voltage microcontroller logic while feeding microsecond-accurate phase signals to the controller.The power conversion stage employs a low-frequency center-tapped transformer topology driven by high-current power MOSFETs configured for push-pull switching. The Arduino executes phase-locked control routines, generating precise Pulse-Width Modulation (PWM) signals aligned with the utility grid's voltage waveform. High-capacity DC-link capacitors stabilize voltage input, while custom gate-drive circuits ensure crisp MOSFET switching transitions to minimize conduction and switching losses.To support continuous power delivery under heavy current loads, the hardware layout integrates heavy-duty aluminum heatsinks for passive thermal management, protecting power semiconductors against thermal runaway. The completed prototype demonstrates accurate phase tracking, safe optical isolation, and stable DC-to-AC power transformation tailored for renewable energy and localized microgrid applications.
